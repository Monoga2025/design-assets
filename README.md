Four images from my working files. Three are prompt briefs captured as screenshots, and one is a portfolio poster.

| File | What it is |
|---|---|
| `agent-mentor-prompt.png` | System prompt for a learning-strategy mentor agent. It requires proposing simple, low-friction methods before any software, and forbids writing code unless explicitly asked. |
| `web-3d-landing-brief.png` | Brief for an AI-assisted landing page for a fictional headphone brand. It asks for generated visuals and a 3D product section, a scroll-driven layout, and a per-run metrics log (credits, tokens, cost in USD). |
| `ideal-client-copy-brief.png` | Brief for an ideal-client sales letter in Spanish: client pains, real proof only (missing data marked as `[DATO]`), style rules, and deliverables (`carta.md`, `carta.html`, `fuentes.md`). |
| `portfolio-poster.png` | Portfolio poster for a freelance mechatronics engineer in Colombia: web pages, video, automation, and CAD services, with featured projects and a work process. Includes a photo of the owner. |

These are working references, not final brand assets. The poster contains claims (such as output volume) that the owner should verify before reuse.
